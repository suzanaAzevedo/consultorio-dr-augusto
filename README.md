# Consultório Médico Dr. Augusto Dutra Ribeiro

Landing page e pré-agendamento online — Itaqui - RS (CNES 5248787).

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

Build de produção:

```bash
npm run build
npm start
```

## Publicar no GitHub

Repositório Git já inicializado localmente. Após criar um repositório **vazio** no GitHub (sem README), na pasta do projeto:

```bash
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git branch -M main
git push -u origin main
```

Substitua `SEU_USUARIO` e `SEU_REPOSITORIO` pelos seus dados. Se usar SSH:

```bash
git remote add origin git@github.com:SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
```
